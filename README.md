# Проект сайта на Django
#
## О проекте
#### Проект маленького магазина, где зарегистрированные пользователи могут выставлять свои товары. Присутствуют модераторы(Права выдаются отдельно)
#
### *Для виртуального окружения использовался Poetry 
#
### Чувствительные данные
В проекте присутствует .env.sample . Необходимо создать копию файла с названием .env
 и заполнить данными, изходя из вашей базы данных
#
### Клонирование проекта
```commandline
git clone https://github.com/BrutalCutie/djangoprobe.git
```

## Создание виртуального окружения и установка зависимостей
1. ```poetry lock```
2. ```poetry shell```
3. ```poetry install``` 


## Запуск
```python manage.py runserver```

## Кастомные команды
**add_moder_group** - Добавление группы модератора
